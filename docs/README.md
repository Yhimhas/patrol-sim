# 项目文档

这里整理了巡检机器人项目的需求和结业材料模板。技术方案由学员自行选择。请将各模板中的 `XXX` 替换为项目实际信息。

| 文档 | 用途 |
| --- | --- |
| [01 项目需求](01_项目需求.md) | 确定目标版本，对照各层级的功能与验收方式。 |
| [02 小组分工](02_小组分工.md) | 记录成员、任务、交付物和实际贡献，个人项目也可填写。 |
| [03 项目架构与接口](03_项目架构与接口.md) | 补全架构图、模块职责和前后端接口约定。 |
| [04 运行与结业提交](04_运行与结业提交.md) | 填写运行入口和 Docker 部署步骤，汇总结业材料。 |
