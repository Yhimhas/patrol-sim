## 项目介绍

### 项目介绍
- 小组或个人：个人项目（GitHub: 911110120）
- 项目简介：在浏览器中模拟二维地图上的巡检机器人，访客可查看地图、手动控制机器人、查询规划路径、观察前方传感器读数，并启动自动巡检依次到达检查点。
- 完成内容：二维网格地图区分空地、障碍、检查点与机器人；按钮与键盘四方向手动控制，越界或撞墙时后端拒绝且位置不变；A* 绕障路径规划，不可达返回原因；前方虚拟传感器反馈受阻来源与可通行距离；按检查点顺序自动巡检，可停止、可复位；巡检结束自动返航起点并统计步数、路径长度、耗时与覆盖率；编辑模式点击格子增删障碍，障碍可动态扰动并在路径受阻时自动重规划；后端 API、pytest 与编译检查 CI、单容器 Docker 部署。
