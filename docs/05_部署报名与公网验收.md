# 部署报名与公网验收（摘要）

需要公网展示时，按模板仓库 `docs/05_学员部署操作流程.md` 执行：

1. 在个人仓库开发并推送；构建公开的 `linux/amd64` Docker 镜像（默认 GHCR），复制镜像摘要。
2. 从报名分支向 `Yhimhas/patrol-sim:main` 提交一条 Open 状态的 PR，标题格式「部署报名｜组名｜项目名」。
3. PR 正文写明巡检场景、核心功能、访客可体验的操作、容器内 Web 端口、所需环境变量与可访问验证路径。
4. 收到工作组提供的展示地址后，在浏览器验证首页、地图、手动控制、状态反馈与专项功能；通过后把地址填入根 README「在线演示」。

本项目容器内 Web 端口为 `8000`，无需额外环境变量；验证路径为 `/` 与 `/api/state`。
