# 运行与结业提交

提交前请从干净的仓库副本按本文步骤完整运行一次，并确认验收人员能访问仓库与成果材料。

## 本地运行

- 使用的操作系统和环境版本为 Windows 11 + WSL2（Ubuntu 26.04）、Python 3.12、Node.js 24、npm 11。
- 前后端启动顺序为：先启动后端（8000 端口），再启动前端（5173 端口）。

  ```bash
  # 终端 1：后端
  cd backend
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  uvicorn app.main:app --reload --port 8000

  # 终端 2：前端
  cd frontend
  npm install
  npm run dev
  ```

- 页面入口为 http://localhost:5173 ，后端 API 地址为 http://127.0.0.1:8000 （前端已内置该地址，后端已开启 CORS）。
- 启动后依次点击「前进 / 后退 / 左转 / 右转」，预期看到机器人在地图内移动、状态栏坐标与朝向同步变化；让机器人朝障碍物前进时，页面显示「前方是障碍物，机器人保持原位」，位置不变。

依赖安装、配置、启动命令和单端验证步骤分别见[前端 README](../frontend/README.md)与[后端 README](../backend/README.md)。

## Docker 部署

1. 在仓库根目录执行命令，所需 Docker 环境为 Docker 24+（Docker Desktop 4.x，WSL2 后端即可）。
2. 无需额外配置：基础版不依赖外部密钥，镜像内已包含前端静态产物与后端服务；若后续接入大模型，密钥只放本机 `backend/.env`，不会写入镜像。
3. 使用公开镜像或从源码构建，再执行启动服务：

   ```bash
   # 方式 A：公开镜像（任何人可拉取）
   docker pull ghcr.io/gujianxiaozi1234/patrol-sim:latest

   # 方式 B：从源码本地构建
   docker build -t patrol-sim:latest .
   ```

   ```bash
   docker run -d --name patrol -p 8000:8000 ghcr.io/gujianxiaozi1234/patrol-sim:latest
   ```

4. 打开 http://localhost:8000 ，执行「点击前进 / 后退 / 左转 / 右转」验证页面和 API，预期结果为：页面加载二维地图与机器人、操作后机器人移动且状态同步、撞障碍时提示「前方是障碍物，机器人保持原位」。

   ```bash
   curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8000/api/robot   # 200
   curl -s http://localhost:8000/api/map                                      # 16×12，5 个障碍
   ```

   也可用 compose 启动：

   ```bash
   docker compose up -d --build
   docker compose down
   ```

5. 使用以下命令停止服务：

   ```bash
   docker rm -f patrol
   ```
