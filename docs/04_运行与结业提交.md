# 运行与结业提交

## 本地运行

- 操作系统与环境：Windows / Linux / macOS 均可，需 Python 3.13+。
- 安装依赖（项目根目录）：

  ```powershell
  python -m venv .venv
  .venv\Scripts\python -m pip install -r requirements.txt
  ```

- 启动服务：

  ```powershell
  .venv\Scripts\python -m uvicorn app.main:app --app-dir backend --port 8000
  ```

- 页面入口：`http://localhost:8000`；后端 API 前缀 `/api`；接口文档 `/api/docs`。
- 启动后点击方向按钮或按键盘移动机器人，核对页面坐标、朝向、状态与 `/api/state` 一致；点击空地格子查看规划路径；启动自动巡检观察进度与完成状态，结束后自动返航；可在编辑模式增删障碍，用动态障碍开关观察扰动与重规划。

## Docker 部署

1. 在项目根目录执行构建：

   ```powershell
   docker build -t patrol-sim:local .
   ```

2. 启动容器（本机 8080 映射到容器 8000）：

   ```powershell
   docker run --rm -p 127.0.0.1:8080:8000 patrol-sim:local
   ```

   或使用 Compose：`docker compose up --build`。
3. 打开 `http://localhost:8080`，完成一次手动移动与巡检启动，确认页面与 API 正常。
4. 停止容器：`docker stop` 或 `Ctrl+C`。容器停止后内存状态不保留。
