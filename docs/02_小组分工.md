# 个人分工

- 项目名称：基于 Web 的智能巡检机器人二维仿真系统（Python 版）
- 成员：个人项目（本人）
- 目标版本：基础版 + 标准版专项 + A 类进阶（规则 / 算法类）
- 选择的专项方向：A* 路径规划、虚拟传感器、异常处理、自动巡检；进阶拓展含巡检返航、运行统计、地图编辑、动态障碍与自动重规划
