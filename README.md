# 基于 Web 的智能巡检机器人二维仿真系统

这是培训班结业项目模板。你将在浏览器中搭建一个二维巡检场景，让虚拟机器人在地图上移动，并查看它的位置、朝向和运行状态。完成手动控制后，可以继续实现自动巡检、路径规划和异常处理。

项目采用“统一目标、分层要求、自由拓展”的方式开展。可以独立完成，也可以由 2–5 人组队。学员从零实现基础功能，培训工作组提供需求说明、环境教程、示例代码和助教答疑。

项目可以在普通电脑上完成，无需实体机器人、高性能 GPU 或付费大模型 API。

## 分层目标

| 层级 | 完成内容 |
| --- | --- |
| 基础版（最低目标） | 实现 Web 界面、后端 API 和二维地图。用户可以手动控制机器人，界面能反馈位置、朝向和运行状态。使用 Git 管理代码，配置基础 CI，并提供 Docker 部署方式。 |
| 标准版（推荐目标） | 在基础版上增加自动巡检、BFS 路径规划、虚拟传感器和简单异常处理。可以用巡检点、障碍物检测和无可达路径提示演示这些功能。 |
| 进阶版（自由拓展） | 在标准版上按兴趣选择 AI 模型、Agent、更复杂的路径规划算法、机器人控制或其他工程化功能。进阶功能均为选做。 |

可选择全栈、运维、算法、人工智能、嵌入式与具身智能等专项方向，用于分配项目任务和确定后续学习重点。所有学员采用同一套分层目标。

各层级的验收方式见[项目需求](docs/01_项目需求.md)。

## 开始开发

1. 将模板放入自己的仓库，用 Git 保存开发进度。组队时先确定每个人负责的模块，并约定前后端交换哪些数据。
2. 先用一张小地图接通前后端，让页面能下发移动指令并显示更新后的机器人状态。加入障碍物后，验证机器人遇到障碍或地图边界时的反馈。
3. 为基础功能配置 CI，例如自动运行已有测试或构建检查。整理 Docker 部署文件，并按运行说明从头验证一次。
4. 完成基础版后，按计划加入自动巡检等标准版功能，再决定是否拓展进阶功能。

结业展示时，应能讲清项目的主要功能、基本架构和运行方式，并介绍自己完成的开发内容。
