# 前端说明

## 功能与环境

- 已实现：二维网格地图绘制、机器人朝向箭头、坐标/朝向/状态面板、传感器读数、手动控制按钮与键盘、路径高亮、巡检进度与异常提示；运行统计面板、返航按钮、地图编辑模式与动态障碍开关。
- 前端为原生 HTML/CSS/JavaScript，无构建步骤；地图与状态完全来自后端 API，页面不在本地判断移动能否成功。
- 本地运行无需安装前端工具，由后端静态目录直接托管。

## 本地启动流程

1. 先按[后端说明](../backend/README.md)启动后端服务。
2. 浏览器打开 `http://localhost:8000`，页面会自动读取地图并渲染机器人。
3. 操作方式：
   - 点击上/下/左/右按钮，或使用方向键、`W/A/S/D` 移动一格；
   - 点击任意空地格子，查询从当前位置到该点的规划路径；
   - 「启动自动巡检」按检查点顺序自动行进，走完后自动返航；「停止巡检」中断，「复位机器人」回到起点；
   - 切换到编辑模式后点击格子增删障碍；用动态障碍开关观察障碍扰动与自动重规划。

## 联调验证

- 移动成功后页面按服务端返回状态重绘；受阻、非法输入或网络失败时在提示区显示中文原因，并保留最后一次确认的画面。
- 浏览器开发者工具网络面板可查看 `/api/state`、`/api/move` 等请求与响应。
