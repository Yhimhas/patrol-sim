# 项目内的 agent 资料

## 到哪里找什么

全项目的协作约定填写在根目录的 [AGENTS.md](../AGENTS.md)，前后端特有的约定可写在各自目录的 `AGENTS.md`。

`skills/` 用来放本项目实际使用的技能。技能是一组可重复使用的操作说明，也可能附带脚本。当前模板没有预装技能，目录中的占位文件只用于保留目录，不要求你为了填满它而添加内容。

## 需要技能时再添加

如果一套明确的操作需要反复使用，可以考虑写成技能。提交技能需要的说明、脚本和其他文件，引用文件时使用仓库相对路径。别人拿到项目后，应能找到这些文件，不需要访问你的个人目录。

添加前读清楚技能会做什么，检查它是否与根规则冲突。技能可以补充工作方式，不能放宽操作权限，也不能代替你作决定。

## 提交前打开文件检查一次

不要把整个 `.agents/` 加入忽略规则，也不要因为它是隐藏目录就漏掉。个人登录信息、工具缓存和无关会话不放进来。`.gitignore` 可以按文件名忽略文件，但不能识别 Markdown 正文中的密码，提交前仍要亲自检查差异。
